# Modern Landing Page

A modern and responsive **restaurant landing page** built with **HTML5 and CSS3**.

This project was created as a front-end practice project to improve my skills in **layout design, Flexbox, responsive design, animations, and modern UI styling**.

## Features

*  Responsive design
*  Modern and clean UI
*  Restaurant-focused layout
*  Navigation bar
*  Hero section
*  Menu / food section
*  Restaurant information and highlights
*  Contact / call-to-action section
*  CSS transitions and animations
*  Flexbox-based layouts
*  Semantic HTML structure

## Technologies

* **HTML5**
* **CSS3**
* **Flexbox**
* **CSS Animations & Transitions**

## Purpose

The main goal of this project was to practice building a complete landing page from scratch using pure HTML and CSS.

Through this project, I practiced:

* Structuring web pages with HTML
* Creating layouts with Flexbox
* Building responsive sections
* Working with positioning and `z-index`
* Creating navigation bars and UI components
* Using pseudo-elements
* Adding transitions and animations
* Improving visual hierarchy and spacing

## Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/Modern-Landing-Page.git
```

Open the project folder and launch:

```text
seif1.html
```

You can also open it directly in your browser.
